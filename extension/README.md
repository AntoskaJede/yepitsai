# YepIts.ai Chrome extension

Manifest V3. Adds a "Summarize with AI" button to YouTube watch pages and shows the summary in Chrome's side panel. Talks only to `https://yepits.ai/api/*`.

- `content.js` / `content.css` — injects the button, survives YouTube's SPA navigation.
- `background.js` — opens the side panel and relays the current video URL.
- `sidepanel.*` — the UI. Works without an account (3 free summaries a day, IP-based, same as the website). Sign-in adds history sync and Pro.
- `icons/` — generated from `public/favicon.svg`: `rsvg-convert -w 128 -h 128 ../public/favicon.svg -o icons/icon128.png`.

## Load locally
`chrome://extensions` → Developer mode → Load unpacked → this folder.

## Package
```bash
./extension/build.sh
```
Produces `dist/yepitsai-extension-<version>.zip`. Bump `version` in `manifest.json` before each store upload.
