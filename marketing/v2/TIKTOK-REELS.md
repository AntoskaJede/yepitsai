**Quick context:** The first idea ("Rickroll summary") is clever but is the single most recycled "AI summarizes famous video" format on short-form. Saving it for week 3+ when the algorithm already knows your account. Replacing it with a higher-hook variant.

## Cross-cutting tips

- The first 1–2s decide everything. Open on the *result* (a summary on screen, a number on a calculator), not on the input box.
- No face required, but text-overlay density matters more — frame every beat so the silent-scroll still tells the story.
- Always end with the URL on screen + "link in bio".
- Reply to comments with video responses — TikTok/Reels algorithm weights creator-reply comments as 2–3x.
- Pin a comment under each video: "If you try it and it doesn't summarize your video, drop the URL below — I'll fix it on stream." Soft ask for engagement + free bug reports.

## Linking + measurement

Each TikTok/Reels bio link should rotate through a `linktr.ee` or `beacons.ai` style page that has 1 link per campaign. Single link target per platform first 7 days: `https://yepits.ai/?utm_source=tiktok&utm_medium=social&utm_campaign=launch_v2`. Tag rotates if running multiple campaigns.

If a video takes off, swap the bio link to a `?utm_content=video_idea3`-tagged URL so we can attribute viral videos specifically.
