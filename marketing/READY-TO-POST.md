Hey, I was dealing with the exact same problem — 2-hour technical videos, no time to watch them all. Tried the manual transcript + ChatGPT route but it got tedious.

Ended up building a tool for it: https://yepits.ai

What it does differently from the extensions mentioned:
- Uses Claude (Haiku) for summaries — handles technical jargon way better than GPT-3.5
- Gives you timestamps that are actually accurate (the transcript timing maps directly to video playback)
- No browser extension needed — it's a web app, so no tracking/permissions concerns
- Free tier: 3 summaries/day, Pro is $7/mo for unlimited

The key thing for technical content: ask it to preserve terminology. Most summarizers oversimplify because they're optimized for general content. Claude tends to respect domain-specific language better.

Would love feedback if anyone here tries it on technical/educational content specifically.
